# 🤖 React Chatbot

A simple and responsive chatbot interface built using **React.js**. This project focuses on building a clean chat UI with reusable React components and modern frontend development practices.

## 🚀 Features

- 💬 Interactive chatbot interface
- 🧩 Reusable React components
- ✍️ Chat input for sending messages
- 📩 User and chatbot message components
- 📱 Responsive design
- ⚡ Fast development with Vite
- 🎨 Custom CSS styling

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- ESLint
- npm
